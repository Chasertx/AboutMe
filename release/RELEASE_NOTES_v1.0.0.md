# AboutMe v1.0.0

Initial public release of the portfolio application.

## Highlights

- Deployed React + Vite portfolio to GitHub Pages
- Configured project-site base path support for /AboutMe/
- Added static-host safe behavior for portfolio data loading
- Improved light-theme contrast and component visual hierarchy
- Included production-ready static bundle and source bundle artifacts

## Tech Stack

- Frontend: React 19, Vite 8
- Backend: ASP.NET Core Web API (.NET 8)
- CI/CD: GitHub Actions
- Hosting: GitHub Pages
